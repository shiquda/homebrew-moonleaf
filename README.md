# Homebrew Tap for Moonleaf

Official Homebrew tap for [moonleaf](https://github.com/shiquda/moonleaf) — the actively maintained wallpaper manager for macOS.

## Installation

Install directly with Homebrew:

```bash
brew install shiquda/moonleaf/moonleaf
```

Or tap first, then install:

```bash
brew tap shiquda/moonleaf
brew install --cask moonleaf
```

## Upgrading

```bash
brew upgrade --cask moonleaf
```

## Uninstalling

```bash
brew uninstall --cask moonleaf
```

## About Moonleaf

Moonleaf is an actively maintained fork of `illufied/moonleaf` (formerly `macpaper`), featuring:
- Support for video, GIF, and static wallpapers
- Multi-monitor and per-Space wallpaper rotation
- Menu bar quick controls and library management
- Online wallpaper discovery (Wallhaven / Pexels)
- Native Swift & Universal binary (Apple Silicon + Intel)

For documentation, release notes, and source code, visit:
- **Repository**: [https://github.com/shiquda/moonleaf](https://github.com/shiquda/moonleaf)
- **Website**: [https://shiquda.github.io/moonleaf](https://shiquda.github.io/moonleaf)
